    向島百花園「春の七草」の催し　新しい年も元気で過ごせるよう願いを込めて
    東京都 報道発表

    向島百花園では、江戸時代の開園当初（文化4年頃）より、園主が年末に籠に植えた春の七草をお得意様にお歳暮として届ける慣わしを受け継ぎ、毎年当園の職員が手づくりで育てた七草を籠に仕立て、新年に皇室に献上しています。 その「春の七草籠の製作実演」を、今年も伝統技能見学会として皆様に披露します。そのほか、お客様にもご参加いただける「わら・竹細工の実演と体験」を開催...
