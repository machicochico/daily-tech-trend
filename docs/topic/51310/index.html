    @IT

    仮想化基盤ソフトウェアのライセンス体系変更によってIT戦略の見直しを迫られた企業は、代替製品への移行を積極的に検討している。ただし移行先の選定や、移行時のダウンタイムの最小化といった課題を前にして、計画が停滞するケースもある。短時間で仮想化基盤を移行し、移行後もDRやランサムウェア対策として活用できる実践的な手段を紹介する。...
