    12月3日から9日は「障害者週間」 東京都では啓発イベント・相談事業を実施します
    東京都 報道発表

    毎年12月3日から9日までは、障害や障害のある方々への関心と理解を深める「障害者週間」です。障害者基本法では、国民に広く障害者福祉についての関心と理解を深めるとともに、障害者があらゆる分野の活動に積極的に参加する意欲を高めることを目的として、この期間が定められています。 この期間を中心に、国、地方公共団体、関係団体等においては、様々な意識啓発に係る取組が展開...
